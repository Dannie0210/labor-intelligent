# Labor intelligent — Manual Lid Inspection

Interactive feasibility demo of a manual food-jar lid inspection line staffed by student interns. Each jar is assigned to one operator for a visualized lid press, and jars displaying a simulated **BOO!** signal are directed to a reject collection zone.

## Cost assumptions

- Initial operators: **2**
- Stipend per operator: **€400 per month**
- Workload: **32 hours per week** (approximately **138.7 hours per month**)
- Implied hourly stipend: **€2.88**
- Planning budget: **€110,000**
- Annual cost model: operators × €400 × 12; excludes other labor overheads and equipment costs.

## Deploy

Enable **GitHub Pages** in **Settings → Pages → Deploy from a branch**, select `main` and `/(root)`. The page is a dependency-free `index.html` and requires no build step.

> This is a concept animation. Detection accuracy, realistic throughput and actual labor/regulatory compliance are not established by this visualization.
