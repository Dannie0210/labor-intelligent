Manual inspection logic

01 — One operator, one lineEach production line has its own operator. Increasing operator count immediately increases the number of visible inspection lines.
02 — Lid press and BOO responseThe operator presses the lid at the inspection station. A BOO response is treated as a defect signal for this concept demo.
03 — Manual reject pushWhen a defect is detected, the operator pushes the jar into the reject area. Throughput, fatigue and actual detection accuracy still require testing.

Concept demonstration for feasibility discussions. Animation speed, defect frequency and line capacity are illustrative. The number of operators changes cost and the number of lines shown, but does not represent a validated productivity model.
